### Employee Performance & Salary Analysis  
*Focus: HR Analytics & Workforce Reporting*

- **The Problem:** Employee salary and performance data lacked structured reporting and meaningful insights for workforce decision-making.

- **The Solution:** Developed SQL queries to analyse employee performance, salary trends, departmental metrics, and workforce insights while preparing datasets for Power BI dashboard reporting.

- **Key Tech:** SQL, Joins, Aggregate Functions, GROUP BY, HAVING, Subqueries, Power BI
